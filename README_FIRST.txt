NEXA 2.0 - READY PACKAGE

1. Keep your existing .env if you already have one. Do NOT share it.
2. If you do not have .env, double-click START_NEXA.bat and paste your OpenRouter API key when asked.
3. The script installs dependencies if needed, starts NEXA, and opens http://localhost:3000.
4. To check syntax/status, double-click CHECK_NEXA.bat.
5. To stop NEXA, double-click STOP_NEXA.bat.

The project uses OpenRouter for /api/chat. Gemini code has been removed.
Job Analyzer and Food Assistant are local endpoints and do not require an AI API call.
Your API key is never included in this ZIP.
